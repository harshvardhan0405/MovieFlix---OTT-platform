🎬 MovieFlix – Modern Movie Streaming UI

MovieFlix is a modern, responsive movie browsing web application inspired by platforms like Netflix. It provides users with an interactive and visually rich interface to explore movies, series, and anime content with dynamic data integration.


🚀 Features
🎥 Dynamic Movie Cards
Browse different categories like Movies, Series, Anime, and Top 10 with smooth horizontal scrolling.
🔍 Live Movie Data (TMDB API)
Click on any movie card to fetch real-time details such as:
Title
Description
Rating
Release date
Poster

🎬 Watch Trailer Feature
Integrated YouTube trailer support using TMDB API.

🖥️ Hero Banner Section
Highlighted featured movie with title, rating, and action buttons like Play and More Info.

🔐 Login Popup UI
Stylish login/signup modal with modern glassmorphism design.

📱 Fully Responsive Design
Optimized for desktop, tablet, and mobile devices.

🎨 Premium UI/UX
Smooth animations, hover effects, and Netflix-style layout.

🛠️ Tech Stack
HTML5 – Structure
CSS3 – Styling & Responsive Design
JavaScript (Vanilla JS) – Functionality & API handling
TMDB API – Movie data & trailers


💡 Highlights
Clean and modular code structure
Smooth scrolling UI (Netflix-style rows)
Dynamic modal popup system
API-based content fetching
Beginner-friendly but scalable project
📌 Future Improvements
🔎 Search functionality
❤️ Watchlist / Favorites system
👤 User authentication (backend)
🎞️ Auto-playing banner trailers
